# ⬡ Pulse Dashboard

Sales & Customer Dashboard for Tire Distributors of GA — Tifton Branch.

## Setup

```bash
npm install
cp .env.example .env     # add your Anthropic API key
npm run dev              # http://localhost:5173
```

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages → Source → GitHub Actions**
3. Add your API key: **Settings → Secrets → Actions → New secret**
   - Name: `VITE_ANTHROPIC_KEY`
   - Value: your Anthropic key from console.anthropic.com
4. Push to `main` — GitHub Actions auto-builds and deploys
